# LightweightToolset

基于 Tauri 2、Rust、React 和 TypeScript 的 Windows 轻量化桌面工具集。应用采用固定主窗口、单实例与单托盘设计，工具可独立启用或停用，设置与统计数据保存在本地。

当前版本：`v0.8.2`。

## 本版更新（v0.8.2）

- **修复 v0.8.1 的严重回归**：静默启动时主窗口按需创建、进程里没有窗口，导致「工具运行时」要等前端页面加载才启动——表现为**静默启动后不打开主窗口时所有功能都不可用**（快捷键、剪贴板、统计、计时器、截图等），「静默启动」通知也要等首次开窗才弹。
- 现在改为**后端在启动流程里自行初始化运行时**（不依赖窗口与前端；带幂等保护），因此静默启动即可正常使用全部后台功能，启动通知也在启动时发出。
- 建议所有使用「静默启动」的用户升级。手动安装覆盖即可，无需改动任何设置。

## 本版更新（v0.8.1）

- **真正做成「托盘轻量」**：主窗口改为**按需创建**——启动与平时（只用托盘、不开界面）不再创建任何窗口，因此也不会拉起 WebView2；关闭主窗口后**立即销毁**并把内存还给系统。实测托盘态的专用工作集从原来的 **≈153MB（开过窗口后）** 降到 **≈10MB**（任务管理器「内存」口径）。
- 采键子进程也做了内存回收（约 16MB → 1MB 左右）。
- 相关回归保障：关窗销毁后进程与托盘仍然存活；托盘图标/托盘菜单/再次启动程序/主窗口快捷键都能正常唤出窗口（会多约 0.3–0.6 秒的首次打开时间）；「关闭应用时＝直接退出」与托盘「退出」仍能真正退出。
- 本轮同步把「托盘低内存」写进项目约束：后续新增功能不得让托盘态常驻重型资源（额外的 WebView 窗口、常驻进程等）。

## 本版更新（v0.8.0）

- **快捷键提示浮窗改为原生绘制**：不再使用 WebView 窗口，改用 Win32 分层窗口 + GDI 自绘（屏幕快照做磨砂底），弹出自绘亚克力卡片，同时省掉一个常驻的 WebView2 渲染进程（此前隐藏时仍占用约 58MB）。工具 ID 不变，原有的预设、自定义条目与排序都不受影响。
- **提示外观可 DIY**：新增「设置」入口，可调主题（跟随软件/浅色/暗色）、动画（淡入淡出/上滑/下滑）、停留时长（0.8–10 秒）、模糊与不透明度（浅色/暗色各一套）、弹出位置（X/Y 精确到像素）以及键帽的底色/描边/文字颜色，并提供「恢复默认配置」。
- **提示图标改为线性风格**：新增复制、粘贴、剪切、全选、保存、查找、撤销、重做、贴图、窗口置顶、关闭全部、隐藏/显示、鼠标穿透、主窗口、剪贴板、截图等语义图标，软件级快捷键按动作自动匹配，其余退回键盘图标。
- **实验性功能**：设置里新增「实验性功能」开关（正式版默认关闭，开发版固定开启），打开后出现独立标签页；首项为「图标绘制」，用路径数据（24×24，支持 `M/L/H/V/C/Z`）自定义提示图标，带实时预览与使用说明。
- **修复符号键快捷键被当成「呼出主窗口」**：`Ctrl+Win+/` 这类组合此前因键名写法不一致匹配失败，会误弹主窗口；现在统一规范化比较，未匹配的热键不再默认呼出主窗口。
- **修复停用工具后快捷键仍生效**：停用截图后贴图组快捷键不再被注册，重新启用会按配置注册回来。
- **截图与贴图修复**：贴图快捷键只在截图标注阶段生效（其它阶段不再退化成「贴最近一次截图」）；开启关闭确认时「关闭所有贴图」只弹一次确认；修复贴图「鼠标穿透/全部隐藏」状态残留导致新贴图一出生就点不动；修复拖拽选区时偶发一块区域没有压暗。

## 本版更新（v0.7.2）

- 修复一处会把软件整体卡死的问题：剪贴板弹窗与快捷键提示浮窗在同一时刻首次创建时，两个建窗动作会嵌套执行并互相等锁，导致主线程永久卡死——表现为进程和托盘图标都还在，但托盘菜单、快捷键、所有窗口全部没有响应。现在后来者会让路（浮窗退避重试、弹窗排队重试），不再嵌套建窗；让路事件会记进 `<存储目录>/logs/window.log`，便于排查。
- 该问题在 `v0.7.1` 首次安装后第一次使用剪贴板快捷键时最容易触发，升级到本版即可。

## 本版更新（v0.7.1）

- 新增截图「UI 检测」：截图设置里可选 `不检测` / `仅窗口`（「窗口和UI」留待后续版本）；进入截图即默认预选全屏，「仅窗口」模式下鼠标移到窗口上会把预选切换成该窗口（任务栏、本软件窗口同样可选），单击预选区域进入标注，拖拽则自定义选区、松手确认。
- 快捷键入口归位：剪贴板、窗口置顶的快捷键迁入各自的设置页与工具栏，全局设置只保留「呼出主窗口」；录制框改为单框单按钮、失焦自动保存。
- 数量档位选择器：窗口置顶「最大数量」与截图「历史保留数量」统一为 `1 / 5 / 10 / 15 / 20` 档位选择。
- 快捷键文案统一：修饰键固定按 `Win → Ctrl → Alt → Shift → 主键` 显示（如 `Win+Ctrl+/`），不再出现 `SUPER` 或全大写写法；录制过程中也按同一规则实时显示。
- 快捷键提示预设扩充：新增 `Win+P`、`Win+R`、`Win+T`、`Win+G`、`Alt+F4`，并把截图工具的 6 个快捷键（截图、贴图、恢复、关闭全部、隐藏/显示、鼠标穿透）纳入预设，键值随工具配置实时变化。
- 修复贴图组快捷键不弹提示的问题（此前只有截图快捷键会提示）。
- 主窗口唤起加固：最小化到任务栏时按快捷键可直接还原并前置；窗口记录异常时增加原生兜底；唤出事件写入 `<存储目录>/logs/window.log` 便于排查。
- 截图设置页调整：「UI 检测」独立成项，不再随辅助线设置折叠消失；「显示辅助线」改为整行可点的折叠分组，默认收起。

## 下载与安装

- 最新安装包见 [Releases](https://github.com/THE2580/LightweightToolset/releases/latest)，文件名形如 `LightweightToolset_0.8.2_x64-setup.exe`。
- 安装包内含离线 OCR 模型（约 30MB），因此体积比旧版本大（约 33MB），安装后识别全程本地完成、不需要联网。
- 系统要求：Windows 10 / 11 x64，需要 WebView2 Runtime（系统一般已内置）。
- 程序以管理员权限运行（启动时会走 UAC）：按键采集依赖低级键盘钩子，需要覆盖同等级及更低完整性的窗口；UAC 安全桌面与 System 完整性进程不可见。
- 开机自启通过「登录触发 + 最高权限」的计划任务实现，登录时自动启动、不再额外弹 UAC；可在设置中开启「静默启动」，登录后只显示托盘图标。

## 内置工具

### 截图与贴图

- 区域截图：全局快捷键（默认 `Ctrl+Alt+A`）拉起全屏覆盖层，拖选区域；提供放大镜与像素取色、坐标与尺寸标签、对齐辅助线，未选区域按可配置颜色与不透明度压暗。
- 窗口预选：进入截图默认预选全屏；开启「仅窗口」检测后，鼠标移到窗口上会把预选切换成该窗口（任务栏、本软件窗口同样可选），单击预选区域即进入标注，拖拽则自定义选区、松手确认。
- 标注：矩形、椭圆、正圆、直线、箭头、折线、铅笔、荧光笔、马赛克、模糊、文字、序号；二级栏可调线宽、颜色、填充、线型、箭头样式、字号、马赛克强度等，支持撤销/重做与删除模式，完成后复制到剪贴板或保存 PNG。
- 贴图：把截图或已有图片钉在屏幕上（默认 `Ctrl+Alt+P`），支持拖动、边角缩放、滚轮缩放、锁定位置/完全锁定、鼠标穿透、双击动作、关闭确认与窗口阴影；锁定后焦点态阴影由蓝色变为金色。
- 贴图右键菜单：图像处理（左右旋转、水平/垂直翻转、重置）、复制图像、图像另存为、标注、隐藏标注、锁定、关闭。
- 贴图标注：复用截图工具栏（显示在贴图窗口外的独立小窗），退出标注后标注保留在图上。
- 贴图文本选择：内置本地 OCR（PP-OCRv6，纯本地推理、不联网），贴图后自动识别；可在文字上划词复制，也可右键「选择所有文本」；「选中后自动复制」可在右键菜单与工具页开关（默认关闭，关闭时需自己按 `Ctrl+C`）。识别期间右键菜单显示「正在检测文本」，识别完成即释放模型内存。
- 超级拖放：按住 `Ctrl` 拖动贴图，可把图片拖到资源管理器、浏览器、聊天软件等目标，拖动过程带缩小版跟随缩略图。
- 其他快捷键：贴图 `Ctrl+Alt+P`、恢复上次关闭的贴图 `Ctrl+Alt+R`、关闭所有贴图 `Ctrl+Alt+X`、隐藏/显示贴图 `Ctrl+Alt+H`，均可在工具页「快捷键」标签修改。

### 剪贴板

- 自动记录纯文本剪贴板历史，支持搜索、置顶、分页、回收站和手动添加。
- 支持快捷弹窗、内容详情、文本提取以及存储位置与容量管理。
- 可配置全局快捷键；停用工具后会停止轮询并关闭关联窗口。

### 软件使用统计

- 按日、周、月、年聚合前台应用使用时长，提供趋势图、平均参考线和软件排行。
- 支持进程别名、监测开关与离开状态判定；连续无输入达到阈值后暂停累计。
- 仅记录进程名和累计时长，不记录窗口标题、文件路径或输入内容。

### 按键使用统计

- 按日、周、月、年统计物理键盘与鼠标按键次数，支持趋势、平均参考线、排行和方向键循环切换范围。
- 提供主键盘、导航区、数字键盘和鼠标热力预览，并区分主键盘与数字键盘键值。
- 采用 Raw Input 与低级 Hook 采集物理键鼠输入，过滤注入输入与无效 `0xFF` 事件；主程序以管理员权限运行，可覆盖已提权的游戏与启动器。
- 只保存按键名称和聚合次数，不保存输入文本、按键顺序、组合内容、窗口或进程信息。

### 计时器

- 支持正计时与倒计时、拖拽排序、批量暂停/重置和本地系统通知。
- 每个计时器及本地时钟均可打开独立自由窗口；自由窗口默认跟随主窗口主题，也可在标题栏临时切换浅色/深色。
- 工具停用时会暂停运行条目并停止后台 worker。

### 窗口置顶

- 使用全局快捷键切换当前外部窗口的置顶状态，并在工具页集中查看和取消已置顶窗口。
- 快捷键成功置顶或取消时同时显示应用 Toast 与带默认提示音的 Windows 系统通知，主窗口隐藏时也能获得反馈。
- 支持单项取消、全部取消、最大数量限制；独立监护进程会在正式版异常终止后释放责任清单中的置顶窗口。
- 受 Windows UIPI 权限边界限制，无法操作完整性级别更高的窗口。

### 快捷键提示

- 内置常用编辑键、Windows 系统键与本软件快捷键预设，也可自行录制任意组合键。
- 按键时在任务栏上方弹出浮窗提示，支持提示文案编辑、排序与提示次数统计。
- 三条采集通道覆盖不同场景：本软件窗口前台时的页面按键、焦点在别处时的进程内钩子、以及系统或其他软件占用的热键（由独立采键子进程经回环 TCP 回传），并统一节流与去重。

## 应用能力

- 单实例、单托盘、编译期工具注册与统一生命周期管理。
- 软件级与工具级全局快捷键、开机自启（计划任务）、静默启动与关闭行为设置。
- 托盘悬停与系统通知使用中文应用名；静默启动时会发一条启动提示，说明三种唤起主窗口的方式。
- 本地数据目录迁移、存储占用展示、调试日志和在线更新检查。
- 全局弹窗、Toast 和工具页面采用统一交互与视觉规范；深色主题使用中性黑灰表面，并同步覆盖主窗口、快捷弹窗与自由窗口。

## 隐私与边界

- 所有工具均在本地运行，不提供插件系统、远程代码加载、第三方市场或运行时安装外部工具。
- 按键统计不构成键盘记录器：不保存文本、序列、组合键内容或应用上下文。
- 禁用工具会注销快捷键、停止 worker/监听器/计时器并关闭关联窗口，而不只是隐藏界面。

## 开发与验证

环境：Windows、Rust 1.96+、Node.js 24+、npm、WebView2 Runtime。

```powershell
npm install
npm run build
cargo check --manifest-path src-tauri/Cargo.toml
cargo test --lib --manifest-path src-tauri/Cargo.toml -- --test-threads=1
```

调试运行（`npm run tauri dev` 因程序需要管理员权限，会在启动阶段报 `os error 740`）：

```powershell
npm run dev                      # 先启动 Vite
cargo build --manifest-path src-tauri/Cargo.toml
# 把 src-tauri/target/debug/lightweight-toolset.exe 复制到任意可写目录后双击/提权启动
```

开发版使用独立应用标识（`com.the.lightweight-toolset.dev`），数据目录、WebView2 缓存、单实例与开始菜单快捷方式均与正式版隔离，可与已安装版本同时运行。

生成 Windows x64 NSIS 安装包：

```powershell
npm run tauri build
```

更多工程约束与开发版/正式版差异见仓库根目录 `AGENTS.md`。
