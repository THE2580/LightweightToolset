# 已确认事实（长期有效）

- 主窗口 `tauri.conf.json` 默认可见；`app.manage(AppState)` 在基础设置/registry 建立后注册，重活（watchdog、工具 init、快捷键）在其后启动，不阻塞首屏。
- 冷启动统计以 release 构建多次启动为准，不以开发热重启为样本；历史基线：`v0.4.4` 首屏约 `1.1s`、压力样本 P95 `1284ms`。
- 主程序以 High 完整性运行：同级及更低完整性窗口的按键可捕获；UAC 安全桌面与 System 进程不可见。
- 截图工具为原生实现（覆盖层/贴图均为 Win32 窗口 + GDI/GDI+），不走 WebView；OCR 为纯 Rust 推理（tract），不联网。
- 配置/数据目录：正式版 `<存储目录>`（用户可改，本机为 `D:\轻量化工具集`），开发版独立标识下的应用配置目录；截图数据在 `<存储目录>/screenshot/{Screenshots,pins}`。
- 采键通道与限制、锁顺序、浮窗约束、OCR 模型分发等，见 `AGENTS.md`「平台约束与踩坑经验」与 `bugs.md`。
