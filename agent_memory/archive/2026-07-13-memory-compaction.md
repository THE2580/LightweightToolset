## 稳定经验摘要

- 窗口置顶管理员目标受 UIPI 限制；第一版不引入置顶提权 helper。
- High 游戏输入需要最小管理员 helper；主程序保持 Medium，helper 生命周期必须随工具/IPC/主程序结束。
- 修饰符跨 Raw Input/Hook 去重必须先规范化通用/分侧 VK。
- 异常退出置顶清理需要独立 watchdog；正式安装版任务栏结束任务与托盘退出已验收，开发终端关闭不在保证范围。
- 深色主题、全局弹窗/Toast/Tooltip、分段控件和键盘导航的稳定规范保留于 `context.md`。
