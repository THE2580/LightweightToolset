# 归档：2026-11-02 进度压缩

本文件保留 `v0.5.0`〜`v0.6.0` 期间的逐项开发记录，供追溯；当前状态以 `progress.md` / `working_state.md` / `checkpoint.md` 为准。

## 剪贴板优化迭代（v0.5.0，2026-10-31，全部验收并发布）

- 回收站新增「全部清空」：按钮位于回收站标题栏右侧，空回收站禁用；点击弹二次确认（永久删除、不可恢复），确认才删除并 Toast 回报条数；后端命令 `clipboard_purge_trash`。
- `Ctrl+A` 全选当前页：历史/固定/回收站三处生效，不跨页，焦点在输入框时不抢占，已全选时再按取消。
- 快捷弹窗标题栏单行紧凑布局 + 仅图标「历史 / 固定」分段（默认历史）；列表与搜索只作用于当前分段；面板宽高仍由设置控制。
- 快捷弹窗全局搜索：搜索为空保持分段布局；有内容时隐藏分段、搜索框铺满；结果合并固定与历史、固定置顶并显示分组标签；分页按合并结果；清空恢复原布局。切换补 220ms 过渡（分段收起/淡出、搜索框连续变宽）。
- 快捷弹窗焦点驻留：点击面板内非输入区域后异步把焦点还给搜索框；详情/提取弹窗打开或窗口失焦时不抢焦点。
- 通知浮窗（当时代号「系统通知」）：单浮窗、任务栏上方居中、×N 计数不排队、2s 停留、按住 0.5s 节流；去掉 DWM 材质（先露矩形框的根因），改窗口全透明 + 纯 CSS 卡片淡入淡出。
- 分词提取定稿：按原文顺序、记录词位、全选可还原原句；已知不完美（序号带句点、`×N` 只剩 `N`、单字虚词保留）经用户确认接受，不再改动。

## 快捷键提示工具（v0.6.0，2026-11-01〜02）

> 详细设计与最终结论见 `progress.md`、`bugs.md`、`AGENTS.md`；此处只留过程要点。

- 工具页：预设 / 自定义分区；预设不可删除、键值锁定、可改文案与启停；自定义可增删改；「恢复常用预设」只重置预设。
- 排序：名称 / 创建时间（仅自定义）/ 提示次数 + 升降序，选择记忆；次数在行 tooltip，后端 5s 节流落盘。
- 编辑弹窗：录制框与文案框等高；关闭/保存走 170ms 淡出；保存失败复位 `closing`，不卡遮罩。
- 浮窗：固定 560 宽窗口 + 卡片 `max-content` 居中（拒绝按字符估宽）；显示期间每 400ms 重压置顶；预设各配图标，自定义用键盘图标。
- 录制：状态只跟录制框焦点绑定；录制期间钩子吞键并暂停全局热键，`Win+I` 这类可录。
- 采键：页面上报（Chromium 前台普通键）、进程内钩子、独立子进程（`--shortcut-tip-helper` + 回环 TCP）三路。
- 排除方案：Raw Input 兜底（实测收不到被注册走的 Win 组合键）。
