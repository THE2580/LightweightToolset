## 计时器第一版范围摘要

- 主窗口内计时器页，最多 20 个。
- 支持正计时/倒计时、名称、备注、开始、暂停、重置、删除、编辑。
- 倒计时默认 `25:00`，上限 `99:59:59`。
- 倒计时结束触发 Windows 系统提醒弹窗，已置顶。
- 正计时不显示通知开关。
- 运行中计时器重启后恢复为暂停，不追补后台时间。
- 数据结构预留排序、通知、悬浮窗/独立窗口状态。
