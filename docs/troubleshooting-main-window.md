# 主窗口唤不出 / 软件像「死」——问题现场取证清单

> 适用：托盘图标还在，但点托盘「显示主窗口」、点托盘图标、按「呼出主窗口」快捷键都唤不出主窗口，且其它功能（快捷弹窗等）也不可用。
> 目的：在**不重启、不清理**的前提下，把判断根因需要的证据一次收齐。整个过程 3–5 分钟。

## 一、先别做这些

- 不要先退出软件 / 结束进程 / 重启电脑——`window.log` 会保留，但进程内状态和 WebView 进程现场会丢失。
- 不要删除 `%APPDATA%` 下任何目录，也不要用「修复/重装」。
- 不要连续点很多次托盘，点 2 次（一次托盘图标、一次菜单「显示主窗口」）足够。

## 二、记现象（30 秒，手机拍照或截图都行）

逐个做，并把结果记下来：

1. **右键托盘图标** → 能不能弹出「显示主窗口 / 退出」菜单？
2. 菜单里点 **「显示主窗口」** → 有没有任何反应（窗口闪一下、任务栏出现按钮、完全没反应）？
3. 按 **呼出主窗口快捷键**（默认 `Ctrl+Alt+.`）→ 有没有反应？
4. 按一个**工具快捷键**（例如截图 `Ctrl+Alt+A`、剪贴板快捷弹窗）→ 有没有反应？
5. 鼠标**悬停**托盘图标几秒 → 图标会不会突然消失？（消失说明这是上一个进程的残留图标）

> 判读：菜单能弹 = 主线程还活着，问题在「窗口/WebView」；菜单都弹不出 = 主线程卡死。

## 三、取日志（最重要）

按 `Win + R`，输入 `%APPDATA%` 回车，然后找：

| 版本 | 日志路径 |
|---|---|
| 正式版（默认存储路径） | `%APPDATA%\com.the.lightweight-toolset\logs\window.log` |
| 正式版（改过存储路径） | `<你设置的存储目录>\logs\window.log`，如 `D:\轻量化工具集\logs\window.log` |
| 开发版 | `%APPDATA%\com.the.lightweight-toolset.dev\logs\window.log` |

- 把**整个文件**复制一份发我（内容很小，几 KB）。
- 如果文件不存在，说明这次故障没有经过「唤出入口」，也要告诉我。
- 文件超过 256KB 会自动重置，属于正常。

## 四、任务管理器现场（60 秒）

`Ctrl + Shift + Esc` 打开任务管理器 → 「详细信息」页：

1. 找 **`lightweight-toolset.exe`**：有几个？记下 PID、内存、CPU。
2. 找 **`msedgewebview2.exe`**：有没有？如果有，右键 → 「转到详细信息」看它的父进程是不是 `lightweight-toolset.exe`。
   - **完全没有 `msedgewebview2.exe`** → WebView2 已经没了，这是关键线索。
3. 顺手截一张任务管理器图（能看到这两类进程即可）。

## 五、补充上下文（可写在消息里）

- 这次是「开机后第一次点」还是「用了一段时间后」？
- 当时是不是**静默启动**（开机后没看到窗口，只有托盘）？
- 之前是不是把窗口**关闭到托盘**（点了 × 而不是最小化）？
- 电脑是不是刚睡眠/休眠唤醒过？有没有切换过显示器、改过缩放？
- 有没有同时跑**正式版和开发版**（托盘会有两个图标）？

## 六、恢复使用

取证完成后：

- 托盘右键 → **「退出」**，再重新打开软件；或
- 任务管理器里结束 `lightweight-toolset.exe` 后重新打开。

如果重启后立刻又复现，请把「重启后多久复现」也记下来。

## 七、发给我的最小信息包

1. `window.log` 整个文件；
2. 第二节 5 个问题的答案；
3. 任务管理器截图（`lightweight-toolset.exe` + `msedgewebview2.exe` 是否在）；
4. 第五节的时间线描述。

## 附：`window.log` 怎么读

每行格式：`<毫秒时间戳> <事件>`，常见事件：

| 事件 | 含义 |
|---|---|
| `main_window.show_requested webview=alive` | 唤出请求进来了，主窗口下 WebView 子窗口还在 |
| `main_window.show_requested webview=missing` | WebView2 子窗口已消失（页面运行时没了） |
| `main_window.show_requested webview=no_window` | 连主窗口 HWND 都不在了 |
| `main_window.show_failed reason=window_not_found` | Tauri 的窗口记录丢了（会走原生兜底） |
| `main_window.show_ineffective visible=... minimized=...` | `show()` 调用成功但窗口实际没出来 |
| `main_window.show_recovered_by_hwnd` | 已用原生方式把窗口强行还原出来 |
